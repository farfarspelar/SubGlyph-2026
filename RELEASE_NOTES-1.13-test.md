# SubGlyph 2026 1.13-test

Evaluation build based on 1.12-test.

## Changes

- Front-face marking now uses the explicit mirror setting directly. It no longer
  applies the automatic upper-turret mirror used for cylindrical marking.
- Version labels and Linux, Windows, and macOS build names are updated to
  1.13-test.

This evaluation build has not been verified on a physical machine. Simulate and
verify the generated NC program for the target machine before machining.
